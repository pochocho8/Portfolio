# Portafolio — Sergio Morocho Perea

Página única (HTML, CSS y JS en un solo archivo) con el portafolio profesional.

- `public/index.html`: la página.
- `wrangler.jsonc`: configuración para desplegarla en Cloudflare Workers (static assets).

## Despliegue en Cloudflare

Workers & Pages → Create → Import a repository → elige este repositorio.
Cloudflare despliega automáticamente con cada push a `main`.
